Данный парсер для Wildberries создан для прохождения тестового задания и парсит товары по запросу "Пальто из натуральной шерсти. Парсер не использует официальное API Wildberries.

Запускается через скрипт main.py. В консоль выводится progress bar, в котором отображается примерное количество всех товаров, которые необходимо спарсить. После завершения (в том числе и досрочного) работы парсера, результат сохраняется в папку "output_(дата)(время)". В папке вывода должны находиться "products.xlsx" - все товары и "products_selection.xlsx" - выборка из всех товаров по условию из тестового задания. В зависимости от параметров в файле config.py, также в этой папке могут быть "logs.log" - файл с логами и "data_page_(номер)" - ответы сервера, необходимые для дебага.

Из замечаний:

1) У WB своя антибот защита, поэтому создан отдельный скрипт "token_manager.py", который позволяет проходить защиту и получать токен. Однако для работы этого скрипта нужны драйвера браузера для прохождения защиты, которые скрипт сам должен предложить установить. Но при запуске скрипта на виртуальном окружении, этот диалог может не появиться, как у меня, поэтому токен приходится генерировать вручную и вставлять в "token.secret" в папке проекта (возможно, в ближайшем будущем придумаю обход защиты без использования браузера).

2) Многие параметры было бы удобно передавать непосредественно при запуске скрипта, в частности включение/выключение режима дебага, но пока всё делается вручную через config.py.

3) Лучшие значение при запуске, которые из наблюдений я вывел:
	MAX_CONCURRENT_REQUESTS_PAGE = 1
	MAX_CONCURRENT_REQUESTS_CARD = 9
	DELAY_MIN = 3
	DELAY_MAX = 6
При этих значениях реже случались обрывы соединения и ошибки в ответах на запросы
